# v0.2 验收步骤

## 离线完整流程

1. 载入合成示例：站点、公园、道路、研究范围、统计分区、DEM；后两层默认隐藏。
2. 输入“统计地铁站 800 米直线范围内的公园数量”。缓冲和统计应成为两个新图层，原数据保留。
3. 打开属性表及血缘，检查输入 ID / 哈希、距离、空间谓词、运行 ID。
4. 工具箱运行面积 / 长度，再次产生新图层。在“保存的工作流”中运行示例缓冲计数链。

示例只验证计算与交互；直线缓冲不能当作步行服务区。

## SHP / TIFF 与自然语言导入

上传 `sample-data/stations-shapefile.zip`，或自己的 SHP 配套文件。告诉助手“请检查并导入刚上传的数据”，应从收件箱建立实际图层。
上传 `sample-data/synthetic-dem.tif` 并要求导入，显示栅格与波段概况。
遇到缺失 CRS、多个资源 / 子图层，应要求明确，不随意选择。导出 SHP / GPKG 后重导，核对要素数量、字段和 CRS。
离线模式只支持有限明确命令；复杂选择与多步任务请连接模型。

## 真实制图

输入“把指北针放到左上角，图例放到右下角，标题设为‘研究区分析’，导出 PDF”。进入布局查看预览，再分别下载 PNG / JPEG / TIFF / SVG / PDF，核对实际文件。
当前导出不含在线底图；制图 TIFF 是页面图像，栅格数据 TIFF 才保留地理参考。

## Responses 与复杂任务

模型设置使用自己的有效凭据，选择 Responses 与 medium / high 推理。测试连接后尝试：

```text
检查 DEM 和统计分区的坐标系，计算坡度并生成新图层；
统计各分区平均坡度，给结果设色，指北针放左上角，
导出 PDF，并把处理链保存成工作流。
```

工具日志应先检查输入、检索参数契约，再执行算法和出图。失败必须显示真实错误，不能写成成功。再次运行工作流核对结果。
协议模拟测试验证 reasoning 保留与 call_id 对应；真实模型理解和供应商兼容性需用有效凭据验收。

## 持久化与控制

刷新后图层、历史、布局和成果保留；API Key 清空。停止等待当前工具 / 网络调用结束，已有产物保留。重启标记中断，不自动重复执行。
当前本地单用户服务没有多用户访问控制。
