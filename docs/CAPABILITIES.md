# v0.2 能力边界

底层 GDAL 驱动数量不等于应用已经验证的格式数量。`/api/capabilities` 返回当前环境的真实驱动和算法目录。

## 格式

| 类别 | 已开放入口 | 说明 |
| --- | --- | --- |
| 矢量 | SHP、GeoJSON / JSON FeatureCollection、CSV、GPKG、KML / KMZ、GML、FGB、GeoParquet、GeoJSONL、DXF、GPX、TAB、MIF | 受当前 GDAL 驱动、二维几何与 CRS 校验约束 |
| FileGDB | ZIP 内 `.gdb` 目录 | 使用 OpenFileGDB；不是 ArcGIS 工程导入，尚未用独立样本做往返测试 |
| 栅格 | TIF / TIFF、IMG、ASC、JP2、PNG、JPG、BIL、DEM、GRD | 必须有有效地理参考；PNG / JPG 需配套世界文件并明确 CRS |
| 矢量导出 | GeoJSON、属性 CSV、GPKG、SHP ZIP、FGB、GeoParquet、KML、GML ZIP、DXF（工具接口） | CSV 无几何；SHP 附字段名截断映射；受驱动和几何类型限制 |
| 栅格数据导出 | GeoTIFF | 保留分析数据地理参考 |
| 地图出图 | PNG、JPEG、TIFF、SVG、PDF | A4 / A3，100 / 150 / 200 / 300 DPI；PDF / SVG 中栅格以影像嵌入 |

自动测试覆盖 SHP 配套文件与 ZIP、GPKG / FGB / GeoParquet 往返、CSV 语言导入、GeoTIFF / NoData / RGB、原生投影快照和五种真实制图文件。
其他已开放驱动未逐一验证，不承诺与 QGIS / ArcGIS 的所有版本完全互通。

## 分析目录（35）

| 类别 | 算法 |
| --- | --- |
| 几何与数据 | 缓冲、质心、面内点、凸包、外包矩形、多部件拆分、边界、修复、面积与长度、融合、简化、属性筛选、字段计算、重投影 |
| 叠加与关系 | 裁剪、相交、联合、差集、对称差、空间连接、最近邻、面内点计数、规则网格 |
| 点模式与连续面 | DBSCAN、IDW、热力密度 |
| 栅格与遥感 | 栅格计算器、NDVI、栅格裁剪、栅格重投影、坡度、坡向、山体阴影、栅格转面、分区统计 |

距离算法使用适用的局部 UTM，限制经纬跨度不超过 6°、纬度 ±80° 的城市尺度。示例专用点缓冲使用每点 AEQD 和独立椭球顶点距离校验。
面积 / 长度使用 WGS84 椭球；空间连接使用 intersects；点计数使用 covers，包含边界，重叠区域分别计数。
地形要求投影单位为米并假定高程为米；NDVI 需指定正确波段与反射率口径。分区统计包含有效像元数、均值、最小和最大值。
IDW 当前最多 8 个近邻；热力密度使用高斯平滑，不能直接当作所有桌面 GIS 同名算法的等价实现。
重投影保留原生 GPKG 快照，交互地图仍显示 WGS84。

## 限制

- 上传总量 250 MB；ZIP 解包最多 2000 个成员、250 MB，禁止路径穿越 / 符号链接。
- 矢量层最多 100,000 要素；交互预览最多 10,000，后台保留全量。界面显示截断提示。
- 栅格导入最多 1 亿像元，单次分析最多 1600 万像元；DBSCAN 最多 10,000 点，插值最多 250,000 像元。
- 缺失 CRS / 地理参考需要补充；不猜测 GCJ-02 / BD-09。导入要求有效二维几何，尚不能在导入前交互修复被拒绝的文件。
- 离线语言只支持有限明确命令；通用规划需要模型。DAG 绑定本项目图层，不支持跨项目参数替换、断点恢复和执行中改计划。
- 地图导出固定 EPSG:3857；比例尺按地图中心纬度换算，大范围不是全图统一地面尺度。
- 暂无 QGIS Processing / ArcPy、路网、三维、影像深度学习、Earth Engine、在线目录、PostGIS、拓扑编辑、删除 / 撤销、Atlas、跨机器恢复。

本版没有“超过其他项目”的实证结论。需要固定模型、数据和预算，以独立 GIS 参考结果比较正确率、失败率、耗时和费用。
