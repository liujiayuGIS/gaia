# GAIA 0.5.0-beta.5 · 对话消息操作

为右侧助手补上提问和回答的常用操作，沿用 GAIA Atlas / Folio 界面和盖亚图标。

- 提问：复制、引用、编辑为新提问，显示消息时间。编辑后新建任务，原记录和成果保留；取消恢复原草稿，发送失败不丢草稿。
- 回答：复制可读正文、引用追问、重新回答、赞同 / 不满意，以及系统离线语音朗读。反馈保存在本地；语音依赖操作系统提供的可用声音。
- 更多操作：复制 Markdown、保存回答、导出本轮对话。Markdown 支持标题、列表、表格与独立代码复制，不执行原始 HTML。
- 引用带有来源与内容快照，限当前会话；较长原文标记节选。重新回答只读原任务记录，不开放 GIS 工具，不重复执行分析、删除或出图。原任务失败或未核验状态不会因文字改写而消失。
- 桌面复制使用受限原生剪贴板写入通道，保持渲染器隔离，不开放剪贴板读取。保留图层删除 / 恢复、助手调宽、中文 SHP 与 DeepSeek 兼容修复。

支持 macOS Apple Silicon（macOS 15+）及 Windows x64。退出旧版后安装新版，工作区独立保留；可下载文件以 Release 实际列出的安装包为准。
