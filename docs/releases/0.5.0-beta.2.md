# GAIA 0.5.0-beta.2 · 桌面预览版

本版同步当前 GAIA 工作台、Harness 与制图代码。采用 Atlas 地图工作区、Folio 出图模式及真实执行流程抽屉，保留右侧独立助手。

- QGIS 布局新增四种指北针、实际比例尺样式目录、五种高程色带；可设置等高线、山体阴影与图例精度。
- 使用实际安装的字体目录，可设置全图与单元素字体、字号、字重和颜色；界面字体也可单独切换。
- 手动编辑、自然语言样式指令、工程保存与导出使用同一份配置。
- 同步会话连续、任务恢复、审批、结果与空间核验能力；标准工具、插件与代码执行保留。
- 安装包包含最新用户手册，可从“帮助 → 打开本地用户手册”读取。

## 安装与更新

下载本次 Release **实际列出的**安装包及同名 SHA-256 文件。macOS arm64 适用于 Apple Silicon，macOS x64 适用于 Intel；均要求 macOS 15 或更新。Windows x64 安装包如已列出，适用于 Windows 10/11 64 位。

退出 GAIA 后替换程序或运行新版安装向导。用户工作区与程序分开保存；重要项目请先备份。首次解压运行时可能需要几分钟。旧版运行时如校验和相同会复用，不需要重复安装 QGIS。

macOS 使用 ad-hoc 签名，尚无 Apple Developer ID 与公证；Windows 尚无商业签名。不会要求关闭系统整体安全检查。
