# GAIA 0.5.0-beta.3 · 导入与模型兼容修复

本版修复中文 Shapefile 导入和模型输出预算问题，保留 Atlas / Folio 界面、GAIA 名称和盖亚图标。仅提供 macOS Apple Silicon（arm64，macOS 15+）与 Windows x64 安装包，不再分发 Intel Mac。

- Shapefile 依据 `.cpg` / DBF 声明读取文字编码，支持手动指定 UTF-8、GBK、GB18030 等。声明缺失且存在非 ASCII 文本时要求明确编码，避免静默导入乱码。
- 对明确识别为多字节字符在字段名长度边界截断的情况，在临时副本中生成唯一安全别名；保留原文件、原始字段字节和别名映射，并显示警告。无法恢复已经丢失的完整原名，字段含义须核对。
- 属性值无法按所选编码解码时拒绝导入，不丢弃记录、不有损替换。直接导入、助手导入和离线明确编码指令共用此机制。
- 每轮输出预算从固定 2000 tokens 改为默认 8192，可在模型设置选择更高预算。推理也可能占用预算；须在所用服务商支持范围内选择。
- 达到上限时记录预算和安全诊断，可提高预算后从原检查点继续。不执行截断的工具调用，也不重复已经确认完成的步骤。
- 保留 DeepSeek 返回的 `reasoning_content` 并随工具结果回传，修复思考模式工具链的协议兼容缺口；跨任务摘要作为资料上下文装配。状态保存在本地检查点，界面不展示原始推理内容。旧版未保存的协议状态不能恢复，必要时应新建任务。

退出旧版 GAIA 后运行新版安装器或替换应用。工作区与程序分开保存。下载本 Release 实际列出的安装包及同名 SHA-256 文件。仓库公开，下载无需登录。

macOS 使用 ad-hoc 签名，尚无 Apple 公证；Windows 尚无商业代码签名。本版模型协议测试使用模拟响应，不替代具体账号、模型和服务商的真实连通性验证。
