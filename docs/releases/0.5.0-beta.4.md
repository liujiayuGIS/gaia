# GAIA 0.5.0-beta.4 · 图层管理与助手调宽

本版补上工作区图层删除与恢复，以及右侧助手的可调宽度。沿用 Atlas / Folio 界面、GAIA 名称与盖亚图标，保留 beta.3 的中文 SHP 和 DeepSeek 兼容修复。

- 图层行增加删除入口，适用于矢量和栅格。移除工作区图层，保留源文件和本地恢复数据；提示条可撤销，也可以自然语言要求恢复。不会永久销毁文件或批量删除要素。
- 注册 `remove_layer`、`list_removed_layers`、`restore_layer`，模型和明确的离线命令均可执行。多个候选时要求明确目标，不能用隐藏冒充删除。
- 移除后同步清理绘制顺序和布局绑定；历史运行记录仍可导出。已完成删除步骤可安全复用，外部恢复后不会在续跑时再次悄悄删除。
- 拖动地图与助手间的分隔线调整宽度并自动保存。支持方向键、Home / End、双击 / Enter 复位及 Esc 取消拖动。
- 地图与出图模式共用宽度偏好，版式工具和地图保留最小操作空间；窄窗口沿用独立页面导航。

仅提供 macOS Apple Silicon（arm64，macOS 15+）及 Windows x64。退出旧版后安装新版；工作区独立保存。安装包以本 Release 实际文件为准，下载无需登录。

macOS 尚无 Apple 公证，Windows 尚无商业代码签名。实际验收与边界见 [交付状态](https://github.com/liujiayuGIS/gaia/blob/codex/desktop-beta2/docs/DESKTOP_STATUS.md)，操作见 [用户手册](https://github.com/liujiayuGIS/gaia/blob/codex/desktop-beta2/docs/USER_GUIDE.md)。
