# 空间语义与成果核验

这次迭代在现有 LangGraph Harness、工具注册表和 QGIS 插件之间加入质量检查。界面和插件调用方式保持兼容。算法能运行不等于方法正确；报告分别记录错误、警告、核验范围和未验证项。

## 执行链

1. 模型、手动工具或工作流选择算法、输入与口径。
2. 共享前置钩子读取实际文件版本、语义声明及算法契约。缺少关键事实时返回需要补充的信息，不编造日期或单位。
3. 原插件执行算法，输出仍发布为独立图层。
4. 独立核验器读取输入和成果文件，用另一条计算路径复算。核验失败时保留成果和错误证据，但工具结果不标成功。
5. 运行结束前汇总质量报告。模型任务最多进行两轮质量返工；审批拒绝或关键事实缺失时不自动重试。
6. 出图另有程序检查与模型视觉审阅。运行记录可下载为 JSON。

通用图状态、恢复和审批继续复用 LangGraph / SQLite；矢量、投影、栅格与路网复算使用 Shapely、GeoPandas、PyProj、Rasterio 和 SciPy。没有重新实现 GIS 运算引擎。

## 可执行契约

`get_spatial_contract` 读取算法族规则，`preflight_analysis` 只检查不执行，`run_algorithm.context` 携带口径。运行请求中的显式用户要求优先于模型工具参数，模型不能将严格验收降为标准验收。

- 距离：QGIS 平面距离与坐标单位一致；经纬度不能默认作米使用。内置距离工具使用自己的局部投影。
- 路网：线几何、步行/骑行/驾车、最短距离/最快时间成本、速度和方向字段。最快路径成本为小时，速度为 km/h，15 分钟必须换算为 0.25 小时。
- 人口：声明每像元人数或密度，以及 people、people/km2 或 people/m2；拒绝直接将密度求和当人数。面积加权积分、边界权重与重采样守恒仍需专门方法，当前未自动证明。
- 地形：需有高程为米的声明，并使用米制水平投影。
- 栅格：逐像元运算的 CRS、尺寸、原点、分辨率同时对齐；分类数据只能用适用的最近邻/众数重采样。
- 时间和字段：按任务声明必要字段及最大日期差。未设置日期约束时不假设所有数据同年。

图层的“数据含义与时间”或 `set_layer_semantics` 保存数量、单位、日期、来源及依据。声明绑定文件哈希，输入变化后失效。用户声明是来源证据，不等于系统独立证明了原始数据真实性。

## 独立核验范围

|任务|当前独立检查|适用前提和边界|
|---|---|---|
|面叠加|输入并集的集合运算与成果对比；测量对称差面积|城市/区域尺度（跨度不超过 6°、纬度 ±80°）；不证明属性分配|
|面内点计数|区域保留、逐区域空间谓词复算、联合范围去重数|普通 Point 计数；QGIS 原生口径排除边界，内置口径包含边界；分类/加权统计未覆盖|
|点缓冲|边界顶点半径复算|最多 50 个点；曲线近似误差、线面缓冲和融合缓冲未完整证明|
|逐像元栅格|输出网格、有效值有限性、所用波段的 NoData 传播|最多 1600 万像元；不证明任意表达式的科学含义|
|最短路径|重新构造有向图、连通与方向、最短成本和输出成本、已在路网顶点的请求端点|预先打断的米制路网；最多 50 万有向边/20 条输出；非零拓扑容差、边中吸附、多点对应和转向限制未覆盖|
|其他算法|已有结构、几何有效性和文件检查|明确报告缺少独立领域核验器|

“严格”要求在上述声明范围内完整检查，不接受抽样、超预算或缺少专用检查；仍不代表对真实世界或全部 GIS 性质的证明。自定义代码可以调用 `verify_spatial_result` 复用适用规则，但必须如实声明方法与输入。

## 地图检查与出图

QGIS 导出后额外生成 120 DPI 审图预览，从原生布局读取实际元素边界、文本需要尺寸、图例图层、比例尺关联、指北针关联以及实际标注位置。检查包括纸张溢出、文本截断风险、字号、图例覆盖、比例尺有效参数、元素/标注重叠和空白预览。多图层图例现包含主图的全部图层；比例尺初始长度按实际地面距离选择。

“检查出图”打开质量面板。“应用出版版式”调整标题/说明层次，将图例放入右侧留白栏；它是起点，不能保证任意内容自动排版。

模型流程为 `export_map → inspect_map(export_id) → record_map_review`。Responses 使用实际 PNG 的 `input_image`；只有成功发送了对应图片且哈希未变化，才允许记录视觉结论。视觉结论单独标记为模型观察。用户可以在模型设置关闭图片发送；没有图像能力或没有审阅时不能宣称“已经看过地图”。

审图 PNG 与对应布局、哈希、导出 ID 和报告持久保存。程序检查不代替地图事实核对，120 DPI 审阅不代替最终印刷尺寸检查。标签位置最多记录 1500 个，超限明确披露。普通非 QGIS 渲染器缺少原生布局证据时也明确披露。

## 验证方式

- 单元/集成测试构造错误的叠加范围、边界点计数、NoData 泄漏、路线逆行、错误成本、错误终点、版面溢出和图例缺漏，验证能被识别。
- 真实 QGIS 测试核对边界口径、导出文件、非空标注位置、图例内容，并回归绘制顺序与工程保存。
- 浏览器测试：`scripts/qa_quality_server.py` + `scripts/quality-ui-test.cjs`，使用独立公开数据工程。依赖 `scripts/fetch_public_samples.py` 已下载的小型 Census/USGS 样本。
- 模型图像消息和两轮返工使用模拟 Responses 验证；这不是付费模型真实视觉准确率评测。

实现依据：[QGIS 路网算法](https://docs.qgis.org/3.40/en/docs/user_manual/processing_algs/qgis/networkanalysis.html)、[QGIS 布局导出与标注结果](https://api.qgis.org/api/3.44/classQgsLayoutExporter.html)、[GDAL 栅格计算](https://gdal.org/en/stable/programs/gdal_calc.html)、[Responses 图像输入](https://developers.openai.com/api/docs/guides/images-vision?api-mode=responses)。
