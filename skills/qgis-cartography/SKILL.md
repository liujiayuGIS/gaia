name: qgis-cartography
description: 使用 QGIS 插件检查真实数据、选择投影、设置符号和标注、制作打印布局，并保存工程、布局模板与导出成果。
version: 1.0.0
required_plugins: [qgis]
---

先列出图层、检查输入 CRS、字段和数据来源。明确主图层、专题指标和单位；必要时向用户澄清。
复杂任务先给出可见计划。检索 QGIS Processing 的实际算法参数，不凭经验编造参数名。
选择适用投影，使用 QGIS 制图插件。设置图例、比例尺、指北针、坐标网格、纸张和来源说明。专题值和图例必须对应实际字段；DEM 需确认高程单位。
出图前预览；导出真实文件。保存 QGIS 工程包与 QPT 布局模板，给出实际下载链接和保存ID，方便再次打开调用。
如需使用 QGIS API 实现特殊符号或布局，通过受限 PyQGIS 代码运行器，输入使用绑定图层，输出写入 output_dir。
验收：图层有效、CRS明确、指标及单位正确、比例尺与投影一致、文件实际存在、工程可重新打开。不能以进程成功代替空间方法正确性。
